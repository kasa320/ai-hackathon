# 書籍の目次データの取得手段

確認日：2026-09-19。輪読の開催回登録で、本の目次（章・節）を自動入力できるかを調べた。

## 結論

- **書誌情報（書名・著者・出版社・ページ数）はISBNから取得できる**（openBD、国立国会図書館サーチ）。
- **目次は、確認した書籍DBからは取得できなかった**。技術書の目次を書籍DBだけで埋めるのは現実的でない。
- **OrcaRouter はWeb検索付きのモデル呼び出しに対応している**（公式ドキュメントで確認）。出版社の書籍ページの目次を検索で取得する方法は候補になる。ただし実際の精度・費用・所要時間は未検証。

## 各サービスの確認結果

| サービス | 確認方法 | 結果 |
| --- | --- | --- |
| [openBD](https://openbd.jp/) | `https://api.openbd.jp/v1/get?isbn=...` で技術書など12冊を照会 | 11冊の書誌情報を取得。目次（ONIX の `TextType=04`）は0冊。技術評論社・翔泳社・オーム社・丸善出版の技術書を含む |
| [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/) | OpenSearch と SRU（`recordSchema=dcndl`）で技術書4冊を照会 | 書誌情報は取得できた。目次に当たる項目は0冊 |
| Google Books API | `volumes?q=isbn:...` | APIキーなしの共有枠が上限到達（429）で未確認 |
| Open Library | `/isbn/{isbn}.json` | 日本の技術書は未収録。英語の技術書1冊も目次なし |
| [OrcaRouter Web search](https://docs.orcarouter.ai/advanced/web-search.md) | 公式ドキュメント | OpenAI の search-preview モデル、Anthropic の `web_search_options`、Gemini の `googleSearch`、Grok の Responses API で検索を利用可能。検索呼び出しごとに課金される |

## 未検証・注意点

- Web検索で得た目次の正確さ、日本語技術書での取得成功率、1回あたりの費用・所要時間。APIキー取得後に数冊で試す。
- 検索結果からの目次はLLMが整形するため、誤りや欠落がありうる。取得元URLの提示と、登録前の人による確認が必要。
- 出版社サイトを直接スクレイピングする方法は、サイトごとの実装と利用規約の確認が必要なため採らない。
