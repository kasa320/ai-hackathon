# 初期アイデア候補

- 作成日: 2026-09-19
- 状態: 発散・比較中

## 評価観点

- 課題の強さ: ユーザーが実際に困っているか
- エージェント必然性: 複数ステップの判断と実行が必要か
- デモ映え: 短時間で価値が伝わるか
- 実装可能性: 会期中に主要フローを完成できるか
- 独自性: 汎用チャットや議事録アプリとの差があるか
- 効果測定: 時間や金額などで価値を説明できるか

## 候補一覧

| 候補 | 自動化対象 | 主な強み | 主な懸念 |
|---|---|---|---|
| 引っ越し司令塔 | ライフライン、住所変更、退去、粗大ごみ等 | 課題が直感的でデモを物語化しやすい | 対象手続きの絞り込みが必要 |
| 家族総務 | 学校のお便り、通院、行政書類、家族予定 | 「家庭にも総務がある」という切り口 | 個人情報と対象範囲の広さ |
| サークル・自治会事務局 | 入会、集金、日程調整、議事録、催促 | 実データを用意しやすく完走しやすい | ビジネス価値の見せ方 |
| 返品・解約・更新管理 | 期限検出、返品、解約、契約更新 | 回収金額として価値を数値化できる | 外部サイト操作と認証 |
| 介護家族の事務局 | 通院予定、制度調査、家族の役割分担 | 社会的インパクトが大きい | 医療判断との境界、高い正確性要求 |
| 会議後の実行担当 | チケット、メール、予定作成、進捗確認 | 業務価値と技術構成が明快 | 類似サービスが多い |
| 忘れ物回収 | 施設への照会、候補照合、回収調整 | ユニークでデモの物語性が高い | 実サービス連携が乏しい |

## 現時点の有力案

### LifeOps: 家族総務エージェント

家庭内に存在する「名もなき事務」を、ゴールの入力から完了確認まで引き受ける。構想は広く持ちつつ、ハッカソンのMVPは引っ越し業務に限定する。

#### 仮説

家庭では、一人が無償の総務担当者として、検索、期限管理、予約、申請、家族への依頼を担っている。現在の生成AIは調べ方を回答できるが、実際の事務を完了までは進めてくれない。

#### MVPのデモフロー

1. 賃貸契約書または引っ越し通知をアップロードする
2. 旧住所、新住所、退去日、家族構成を抽出する
3. 必要な手続きと依存関係を計画する
4. 自治体の粗大ごみルールなど、不足情報を調査する
5. ライフライン停止・開始フォームへ入力する
6. 費用や契約を伴う操作では人間の承認を求める
7. 完了通知を読み取り、タスク状態を更新する
8. 予約失敗などを検出し、代替案を実行または提案する

#### ピッチの核

> 日本の家庭には、給与の出ない総務担当者がいる。LifeOpsは、引っ越し・入学・介護などの「名もなき事務」を完了まで引き受ける家庭向け業務エージェントである。

#### 検証が必要な点

- 実際の引っ越しで最も負担の大きい手続きは何か
- 誰が家庭内の事務負担を担っているか
- 既存の引っ越し手続き一括サービスとの差
- ブラウザ操作をどこまで実装し、どこを模擬環境にするか
- 個人情報を保存しない、または安全に扱う設計

## 暫定順位

1. LifeOps / 引っ越し司令塔: 総合バランスが良い
2. 返品・解約・更新管理: 金銭効果を説明しやすい
3. サークル・自治会事務局: 最も実装リスクが低い
4. 介護家族の事務局: インパクトは大きいが高リスク

この順位は、チーム構成、得意技術、当事者として持つ課題によって更新する。
