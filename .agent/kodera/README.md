# Kodera workspace

AI HACK 2026 に向けた調査、アイデア検討、意思決定、発表準備の記録です。

## ディレクトリ

- `research/`: 公式情報、競合、ユーザー課題などの調査記録
- `ideas/`: アイデア候補、比較、具体化した企画
- `decisions/`: 採用・不採用の判断とその理由
- `pitch/`: 発表構成、デモシナリオ、原稿

## 記録ルール

- 外部情報には、確認日と参照 URL を付ける。
- 事実、推測、提案を区別して書く。
- 重要な方針決定は `decisions/` に残す。
- アイデアを更新しても、却下理由や懸念点は消さない。
- ファイル名は原則として小文字の kebab-case にする。
